# Northlight Animation Studios Website

## Dateien
- index.html = Website-Struktur
- style.css = Design
- script.js = Deutsch/Englisch-Switch + Animationen
- assets/ = Bilder, Logo, Favicon

## Asset-Namen
Bitte exakt so benennen:
- assets/logo.png
- assets/favicon.png
- assets/hero-bg.jpg
- assets/trailer-thumbnail.jpg
- assets/studio-preview.jpg optional

## Start
Öffne index.html im Browser oder lade alles zu GitHub hoch und verbinde es mit Cloudflare Pages.
